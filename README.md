# 西行记 · 玄奘求法交互地图

**在线预览：** <https://asungod.github.io/xixingji-xuanzang/>

一张按《大唐西域记》回放玄奘西行的交互地图。贞观三年（629）自长安西行，贞观十九年（645）东归，传统计十七年；二十九站逐站说书，古地名在前，今地名对照。朱批辨真把史实与《西游记》小说印象分开；互鉴层以阿拉伯语列七座城的后来地名，以孟加拉语读东印度四国。页面提供中文、英文界面与中英预录讲解。

## 本地运行

在本目录打开终端，执行：

```bash
python -m http.server 8080
```

浏览器访问 <http://127.0.0.1:8080/>。进入后先点「入卷」，再点地图站点；点「互鉴」可翻阅阿拉伯读法与东印度四国。

## 作品要点

- **二十九站**：长安至天竺再东归，逐站说书、朱批与时间轴。
- **朱批辨真**：五处辨真、三处路线抉择，落成五朱三墨印谱；小说只作对照，不写进行程。
- **互鉴七城**：石国、康国、缚喝、梵衍那、迦毕试、疏勒、于阗的阿拉伯读法；七世纪这些城还不是后来的伊斯兰城市，迦毕试不等于今天的喀布尔。
- **东印度四国**：奔那伐弹那、三摩呾吒、耽摩栗底、羯罗拿苏伐剌那；三摩呾吒以约 50 公里范围表示，不设单一城点；迦摩缕波不列入；四国不进入二十九站播放。
- **中英预录讲解**：Microsoft Edge 神经语音（zh-CN-YunxiNeural / en-US-AndrewNeural）预录，页面播放本地 mp3。
